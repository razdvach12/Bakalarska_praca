Poziadavky projektu
===================

Subor sluzi ako prehlad dolezitych systemovych poziadaviek a JavaScript/
TypeScript kniznic potrebnych na zopakovanie experimentov.


Systemove poziadavky
--------------------

- Node.js: >= 20.9.0
- npm: odporucane 11.x
- Playwright browser binaries: instalacia cez `npx playwright install`

Verzia pouzita pocas pripravy projektu:

- Node.js: 24.14.0
- npm: 11.9.0


Instalacia backendu agenta
--------------------------

Priecinok:

cd project
npm install
npx playwright install


Dolezite produkcne zavislosti backendu:

- @ai-sdk/google@2.0.43
- @ai-sdk/openai@2.0.71
- @ai-sdk/openai-compatible@1.0.22
- @mastra/core@0.24.5
- @mastra/evals@0.14.4
- @mastra/libsql@0.16.2
- @mastra/loggers@0.10.19
- @mastra/memory@0.15.11
- dotenv@16.6.1
- zod@3.25.76

Dolezite vyvojove zavislosti backendu:

- @types/node@24.10.1
- mastra@0.18.5
- playwright@1.56.1
- tsx@4.20.6
- typescript@5.9.3

Konfiguracia prostredia
-----------------------

Pred spustenim je potrebne vytvorit subor `project/.env` podla sablony
`project/.env.example`. Minimalna konfiguracia pre OpenAI vyzera nasledovne:


PORT=3000
OPENAI_API_KEY=<API_KLUC>



Spustenie
---------

Backend API:
cd project
npm run dev:api


Monitorovacie UI:
cd project/monitor-ui
npm run dev
